## Severity Definitions

**Critical**: System is unusable, data loss, security vulnerability, or blocking deployment
- Example: Authentication completely fails, preventing user access

**High**: Major functionality broken, significant user impact
- Example: Task creation fails consistently

**Medium**: Minor functionality affected, workaround exists
- Example: Minor UI issue that doesn't block functionality

**Low**: Cosmetic issue, minor inconvenience
- Example: Typo in error message

## Resolution Categories

- **Fixed**: Issue has been resolved and verified
- **Won't Fix**: Decision made not to address the issue
- **Duplicate**: Issue already reported elsewhere
- **Not Reproducible**: Unable to reproduce the reported issue
- **External**: Issue caused by external dependency
