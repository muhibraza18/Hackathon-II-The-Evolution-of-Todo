# Skill: Implement Feature

## Description
Fully implements a feature with complete working code across frontend and backend.

## Usage
/implement-feature <spec-path>

## Instructions
- Read `@specs/<spec-path>.md` and all referenced specs
- Implement complete, production-ready code
- **Backend**: Create/update models, routes, business logic
- **Frontend**: Create/update components, pages, API integration
- Follow architecture patterns in `@frontend/CLAUDE.md` and `@backend/CLAUDE.md`
- Use the API client pattern for frontend-backend communication
- Include proper error handling and loading states
- Add TypeScript types and Python type hints
- Ensure authentication checks where required

## Examples
- `/implement-feature features/authentication`
- `/implement-feature features/task-crud`
