# Skill: Scaffold Code

## Description
Creates initial code structure with files, folders, and boilerplate (no full implementation).

## Usage
/scaffold-code <target> <description>

## Instructions
- Create necessary files and folders in `/frontend` or `/backend`
- Add basic boilerplate code and imports
- Include TypeScript/Python type definitions and interfaces
- Add TODO comments for actual implementation
- Follow project structure from `@CLAUDE.md`, `@frontend/CLAUDE.md`, or `@backend/CLAUDE.md`
- Do NOT implement full business logic yet

## Examples
- `/scaffold-code frontend "Task list page and components"`
- `/scaffold-code backend "Task API endpoints"`
