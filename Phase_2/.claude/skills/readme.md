# Skill: README

## Description
Creates or updates comprehensive project README.md documentation.

## Usage
/readme

## Instructions
- Create/update `README.md` in root directory
- Include sections:
  - Project overview and purpose
  - Technology stack
  - Project structure (monorepo layout)
  - Prerequisites and installation
  - Environment setup
  - Running the application (development and production)
  - API endpoints documentation
  - Authentication flow
  - Deployment instructions
  - Troubleshooting common issues
  - Contributing guidelines
- Use clear formatting with code blocks and examples
- Reference specs with links to `/specs` directory
- Follow markdown best practices
